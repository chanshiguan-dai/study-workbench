# 学习工作台

这是可部署到 GitHub Pages 的 iPad PWA 版本。

## 首次发布

1. 在 GitHub 新建一个公开仓库，仓库名建议使用 `study-workbench`。
2. 打开仓库，选择 **Add file > Upload files**。
3. 上传本目录内的全部文件和 `icons` 文件夹，并提交到 `main` 分支。
4. 打开 **Settings > Pages**。
5. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`，然后保存。
6. 等待一两分钟，GitHub Pages 会显示固定网址。

## 安装到 iPad

使用 Safari 打开 GitHub Pages 网址，点击分享按钮，再选择“添加到主屏幕”。

## 更新与数据

更新时继续上传并覆盖同名文件，不要更换仓库或网址。应用数据保存在浏览器本地，更新网页不会主动删除数据。更新前建议在“数据”页面导出一份 JSON 备份。
