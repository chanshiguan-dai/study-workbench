# 学习工作台

专注计时、每日待办、DDL、日历记录和手动补记学习时长。

## 直接使用

**网页地址：[打开学习工作台](https://chanshiguan-dai.github.io/study-workbench/)**

无需下载或安装。在电脑或 iPad 的浏览器中打开上面的地址即可使用。

## 添加到 iPad 主屏幕

1. 使用 Safari 打开工作台网页。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 以后点击主屏幕上的“学习工作台”图标即可使用。

## 数据与升级

记录保存在当前设备的浏览器中。升级网页代码通常不会删除记录，但升级前建议进入“数据”页面，点击“导出备份”保存 JSON 文件。需要恢复时，在同一页面点击“导入备份”。

请勿清除 Safari 网站数据，否则本地记录可能丢失。
